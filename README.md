👑 RPG Reinos em Guerra

Bem-vindo ao RPG Reinos em Guerra, um projeto de site de jogos inspirado no universo medieval e fantástico dos RPGs.

O projeto permite que os jogadores criem seus heróis, escolham classes, conquistem pontos e disputem posições em um ranking. A proposta é proporcionar uma experiência de jogo envolvente, com temática medieval, personagens e elementos visuais inspirados em reinos de fantasia.

🎮 Sobre o projeto

O RPG Reinos em Guerra é um site desenvolvido para reunir funcionalidades de um jogo RPG em uma interface temática e intuitiva.

Os jogadores podem acessar o site, realizar cadastro, fazer login, escolher seus personagens e acompanhar seu desempenho por meio de um ranking.

✨ Funcionalidades
🏠 Página inicial: apresentação do jogo e do universo Reinos em Guerra.
👤 Cadastro de usuários: criação de uma conta para acessar o jogo.
🔐 Login: autenticação dos jogadores.
⚔️ Seleção de personagens: escolha entre 10 classes de heróis.
🏆 Ranking: classificação dos jogadores.
👑 Menu de usuário: identificação do jogador conectado e opção de sair.
📱 Layout responsivo: adaptação para computadores, tablets e celulares.

Imagens PNG e JPG: ilustrações, banners e personagens.

🚀 Como executar o projeto
Faça o download ou clone este repositório.
Abra a pasta do projeto.
Localize o arquivo index.html.
Abra o arquivo no navegador.

Também é possível utilizar a extensão Live Server no Visual Studio Code para executar o projeto em um servidor local.

🎯 Objetivo

Desenvolver uma plataforma de RPG com temática medieval, proporcionando aos jogadores uma experiência de interação com personagens, classes e sistemas de pontuação e classificação.

O projeto também tem como objetivo colocar em prática conhecimentos de desenvolvimento web utilizando HTML, CSS e JavaScript.
